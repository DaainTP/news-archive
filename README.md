# news-archive
뉴스 검색 결과 및 요약 저장소

## 구성
- `news/latest.json` : 최신 회차 (통합포털 연동용)
- `news/latest.txt` : 최신 회차 가독용 정리본 (통합포털 게시용 텍스트)
- `news/archive/YYYY-MM-DD.json` / `.txt` : 회차별 보관본

## 정리 형식
각 항목은 아래 4단 구조로 통일한다.

1. **이슈 (사실관계)** — 보도된 사실만 기재
2. **문제점** — 현장에서 터지는 지점
3. **CM단의 관리 / 해결방안** — 실행 가능한 절차 단위
4. **제안서 활용 포인트** — 건설사업관리 제안서 반영 방법

## 수집 기준
- 최근 **1주일 내** 보도만 사용한다.
- 검색 상위에 노출되는 과거 연도 자료(예: 2017·2022년 보도자료)는 제목이 같아도 제외한다.
- 연도 표기가 불명확한 자료는 인용하지 않는다.
- 링크는 검색 결과에서 실제 확인된 URL만 기재한다.
